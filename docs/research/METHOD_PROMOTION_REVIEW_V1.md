# SimpleWay Method Promotion Review V1

Status: CANDIDATE REVIEW
Scope: Language Atlas + Core contracts + EXP-21..EXP-28

## Promotion rule
LAB observations do not become universal truths. Promotion means only that a mechanism is stable enough to become part of the SimpleWay Method contract, while language-specific realization remains in Language Packs and descriptive evidence remains traceable.

## Decisions

| Mechanism | Decision | Destination | Reason |
|---|---|---|---|
| Capability-first planning | PROMOTE | METHOD | Keeps learner outcome separate from grammar realization. |
| Multiple representations | PROMOTE | METHOD | Needed across scripts, channels and support forms. |
| Layered evaluation | PROMOTE | METHOD | Form, meaning and context cannot safely collapse into one boolean. |
| Evidence-grounded progress | PROMOTE | METHOD | Progress claims require traceable observations. |
| Longitudinal acquisition state | PROMOTE | METHOD | One success is not acquisition. |
| Delayed retention observation | PROMOTE | METHOD | Method should revisit capabilities after time; interval remains configurable. |
| Support withdrawal | PROMOTE | METHOD | Method should test reduced scaffolding; no universal autonomy threshold. |
| Context transfer | PROMOTE | METHOD | Method should include changed-context reuse. |
| Representation transfer | PROMOTE | METHOD | Method should cross scripts/channels where the pack supports them. |
| Interaction | PROMOTE | METHOD | Multi-turn use is distinct from isolated production. |
| Mediation | PROMOTE | METHOD | Meaning transformation for an audience is distinct from translation. |
| Generalization boundary | KEEP IN LAB | LAB | Requires multiple novel cases; universal promotion criteria are not established. |
| Retrieval vs restudy | KEEP IN LAB | LAB | Current implementation is descriptive; causal superiority requires real study design/data. |
| Universal mastery score | REJECT | — | Unsupported collapse of heterogeneous evidence. |
| Universal retention interval | REJECT | — | Timing must remain empirical/configurable. |
| Universal grammar sequence | REJECT | — | Violates cross-language findings. |

## Candidate SimpleWay Universal Learning Cycle V1

1. CAPABILITY — define what the learner should be able to do.
2. ENCOUNTER — expose one or more valid language representations in meaningful context.
3. COMPREHEND — establish meaning without requiring translation as the universal mechanism.
4. RETRIEVE / PRODUCE — require active learner response appropriate to the capability.
5. INTERACT / MEDIATE — when applicable, move beyond isolated production into social language use.
6. REDUCE SUPPORT — remove selected scaffolds and observe what survives.
7. TRANSFER — vary context and/or representation while preserving the capability target.
8. REVISIT — observe performance after a recorded delay.
9. RECORD EVIDENCE — preserve evaluation layers, provenance and authority.
10. UPDATE ACQUISITION STATE — aggregate observations without silently declaring mastery.

## Architecture boundary
CORE transports neutral contracts. METHOD orchestrates the learning cycle. LANGUAGE PACK realizes language-specific content. LAB tests claims and promotion candidates. APP renders the experience.
